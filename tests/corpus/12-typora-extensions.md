# Typora 扩展语法与非标准标记

这些语法不是 CommonMark 的一部分，但 Typora 支持，用户在真实文档里会写。
对 Inkstone 来说，它们要么被原样保留，要么被识别成对应的高亮类。

## 高亮

这是 ==高亮文本==，Typora 用来标记重点。

高亮里也可以有 **粗体** 和 `代码`。

## 上标与下标

H~2~O 是水。

X^2^ 是平方。

E = mc^2 。

## 任务列表的变体

- [x] 已完成
- [ ] 未完成
- [X] 大写的 X 也算完成
-   [ ] 缩进的任务项

## Emoji 短代码

:smile: :rocket: :+1: :heart:

## @提及与 #标签

@someone 在这里被提及，#issue-123 是一个标签。

## 圈出的链接

[这是链接](https://example.com)

## 加粗的边界情况

**加粗的结束在行尾**

**加粗后面紧跟文字**，中间没有空格。

**加粗的**开头。

## 斜体的边界情况

*斜体的结束在行尾*

*斜体*后面紧跟文字。

## 波浪号

~~这是删除线~~，而单个 ~ 不是。

## 下标 / 上标的边界情况

这些是 Pandoc 风格的判定边界，两层（lezer 与 remark）必须给出同样的结论：

- 内容里有空格：~这不是 下标~
- 没有闭合：~未闭合
- 反斜杠转义：~\~转义~

行内代码里的 ~不算~ 也不算。

E = mc^2 与 x^(y+z) 的幂次写法不属于上标语法。

## 混排的强调

***粗斜体***、**粗*斜*体**、*斜**粗**体*。

## 顿号与间隔号

顿号（、）、间隔号（·）、间隔号（•）不该被当成列表符号。
