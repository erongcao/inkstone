# 空白敏感的内容

Markdown 里有些结构是靠缩进和空行区分的，序列化时最容易丢。

## 四个空格的缩进代码块

这是普通的缩进代码块：

    const answer = 42;
    console.log(answer);

它和上面的围栏代码块语义相同，但源码完全不同。

## 围栏代码块里的空行

```js
function a() {
  return 1;
}

function b() {
  return 2;
}
```

## 围栏代码块里保留缩进

```python
def hello():
    if True:
        print("缩进要保留")
    return None
```
