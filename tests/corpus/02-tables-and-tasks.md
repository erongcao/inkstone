# 表格与任务列表

## GFM 表格

| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 单元格 1 | 单元格 2 | $1600 |
| 单元格 3 | 单元格 4 | $12 |
| 斑马纹 | 是 | 很整齐 |

不含对齐标记的表格：

| 第一列 | 第二列 |
| --- | --- |
| 内容 A | 内容 B |

表格单元格内可以包含行内 Markdown：

| 功能 | 状态 | 备注 |
| --- | --- | --- |
| **粗体** | ✅ | 支持 |
| *斜体* | ✅ | 支持 |
| `代码` | ✅ | 支持 |
| [链接](https://example.com) | ✅ | 支持 |

## 任务列表

- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 列表语法是必需的
- [x] **格式**、@提及、#1234 引用都可以有
  - [ ] 嵌套的未完成任务
  - [x] 嵌套的已完成任务
- [ ] 另一个未完成项
