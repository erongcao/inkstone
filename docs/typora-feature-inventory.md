# Typora 功能清单（调研基线）

> 来源：Typora 官方支持站 support.typora.io（2026-10-20 抓取）+ Typora 1.13 版本说明
> 用途：本项目的功能对标基线。每条标注 **优先级**：P0 = MVP 必须 / P1 = v1 必备 / P2 = 后续增强
> 标注 **难度**：低 / 中 / 高（高难度的集中在编辑内核与导出管线）

---

## 1. 编辑内核（Typora 的立身之本）

| # | 功能 | Typora 行为 | 优先级 | 难度 |
|---|---|---|---|---|
| 1.1 | **Live Preview（混合编辑）** | 行内样式（`**` `*` `~~` `==` `` ` ``）输入即渲染，标记符号智能隐藏；光标进入时标记展开为可编辑源码 | P0 | **高** |
| 1.2 | **块级渲染** | `###`、`- [x]` 等块级标记在块渲染后隐藏 | P0 | 高 |
| 1.3 | **源码模式（Source Code Mode）** | 一键切换到纯 Markdown 编辑（Typora 用 CodeMirror），再切回混合模式 | P0 | 中 |
| 1.4 | **模式切换保位置** | 源码 ↔ 混合切换后光标位置与滚动位置不变（Typora 1.13 新增滚动保持） | P0 | 高 |
| 1.5 | **光标所在处展开源码** | 光标移入已渲染的标记内部，实时还原为源码形态 | P0 | 高 |
| 1.6 | **表格图形化编辑** | 光标进入表格出现工具条：调列宽、对齐、增删行列、右键菜单 | P1 | 中 |
| 1.7 | **任务列表交互** | 点击 checkbox 直接勾选/取消，即时写回 `- [x]` | P0 | 低 |
| 1.8 | **自动配对（Auto Pair）** | 输入 `*` `~` `` ` `` `_` `=` `$` `^` 等自动配对；选中文字后输入自动包裹 | P1 | ✅ 已实现（2026-10-21，三档可切；规则对齐官方文档 + 官方视频逐帧核实，见 plan.md §3.4） |
| 1.9 | **智能标点（Smart Punctuation）** | 自动引号/破折号转换（可关） | P2 | 低 |
| 1.10 | **严格模式（Strict Mode）** | 切换 GFM 与严格 CommonMark 解析规则 | P2 | 低 |
| 1.11 | **删除范围语义化** | 段落内删=删句；表格内删=删行；代码块内删=删行 | P2 | 中 |
| 1.12 | **拖拽调整表格列宽** | 拖拽表头分隔线改列宽 | P1 | 中 |

## 3. 代码块与语法高亮

- 高亮引擎：Typora 用 **CodeMirror**；Typora 支持约 130 种语言（`support.typora.io/Code-Fences-Language-Support/`）
- 语言名大小写不敏感
- 代码块行号开关
- 代码块内 Tab / Shift+Tab 缩进、代码块源码模式下识别结束围栏
- P0：常见 30 种语言高亮即可（TS/JS/Python/Rust/Go/Java/C/C++/Shell/SQL/JSON/YAML/HTML/CSS…）

## 8. 主题与外观

- Typora 内置主题基于 **GitHub 主题 + CSS 变量** 体系
- 偏好设置里的样式项：字体 / 背景 / 写作区宽度 / 标题大写 / 列表样式 / 标题自动编号 / TOC 层级 / 代码块主题 / 聚焦样式 / 任务删除线样式 / 图表样式
- **自定义 CSS** 覆盖（用户级 CSS 文件 + 主题级 CSS）
- 主题可从 CSS 文件导入；Typora 官方有主题商店，第三方生态 VLOOK 等
- P0：主题系统（CSS 变量 + 用户 CSS 覆盖 + 明暗双主题）
- P1：主题导入导出

## 9. 导出（Typora 的第二支柱）

### 9.1 原生导出
| 格式 | 优先级 | 说明 |
|---|---|---|
| HTML（含主题样式） | P0 | 可选是否内嵌大纲；支持 Append in `<head>` / `<body>` |
| HTML（无样式） | P1 | 干净 HTML |
| PDF | P1 | 纸张尺寸 / 主题 / 分页符 / 页眉页脚 / PDF 元数据 / 自定义封面 |
| 图片 | P2 | 宽度与字号可调、图像质量可调、主题 |

### 9.2 Pandoc 桥接（Typora 通过 pandoc 支持）
DOCX / ODT / RTF / EPUB / LaTeX / MediaWiki / RST / Textile / OPML / RevealJS 幻灯片 / 其他 Markdown 方言

- 导出项**可自定义**：增删、重排、重命名、快捷键绑定
- 模板可分三类：**原生导出器** / **Pandoc** / **自定义命令**
- 自定义命令支持 `${currentPath}` `${today}` `${title}` `${author}` `${pageNo}` `${pageCount}` `${outputPath}` 等变量
- Pandoc 导出先转 **native AST** 再转目标格式（保证解析规则一致）
- 支持 YAML front matter 覆盖导出设置（原生格式需显式开启开关，出于安全）

### 9.3 导出变量
`${outputPath}` `${outputFileName}` `${outputFileFullName}` `${currentPath}` `${currentFileName}` `${currentFileFullName}` `${currentFolder}` `${today}` `${pageNo}` `${pageCount}` `${totalPages}` `${title}` `${author}` 以及任意 YAML 键（含 `a.b` 嵌套取值）

## 附：Typora 版本节奏参考

- 1.0（2021-11）正式版，2.0 至今仍在 1.x 迭代，最新 1.13（MathJax 4 + Mermaid 11.13）
- 功能演进主线：YAML → LaTeX → TOC → 代码高亮 → 上下标 → 下划线 → 高亮 → 图表 → 本地文件链接 → 表格编辑 → HTML → 图片管理 → 大纲 → 字数 → 专注/打字机 → 深色主题 → 文件树/列表 → 快速打开 → 全局搜索 → 导出管线
- **结论**：Typora 是 5 年持续打磨的产物。开源项目应从「编辑内核 + 文件管理 + 导出」三根支柱切入，而非追求功能对等。
